# Web Based Facial Authentication System

## Overview

The Web Based Facial Authentication System is a Full Stack Web Application that utilizes Artificial Intelligence (AI) and Computer Vision to provide secure and passwordless user authentication through facial recognition. The system enables users to register and log in using their facial features instead of traditional passwords, offering enhanced security and a seamless user experience.

## Project Description

This application captures facial images, extracts unique facial features, and performs real-time identity verification. By leveraging biometric authentication, the system minimizes the risks associated with password theft, weak credentials, and unauthorized access. The solution provides a fast, contactless, and user-friendly authentication mechanism suitable for modern web applications.

## Working Process

1. User registers by capturing facial data.
2. Facial features are extracted and securely stored in the database.
3. During login, the system captures a live facial image.
4. The captured face is compared with stored facial encodings.
5. If a match is found, the user is authenticated and granted access.
6. Authentication logs are maintained for security and monitoring purposes.
